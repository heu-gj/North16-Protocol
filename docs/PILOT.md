## 3. 分阶段验收

| 阶段 | 必须得到的结果 |
| --- | --- |
| 预检 | 固定三段来源、实际视频数、尺寸/编码、日志数、预计容量、缺失列表 |
| 提取 | 全部成功帧与 meta；容器帧数、解码帧数及错误分别对账 |
| 时间 | 原始时间/PTS 保留，无法证明映射时保持 unresolved；不得按行 zip 绑定 |
| 标准索引 | 每张图有稳定 ID、完整相对路径和元信息；未标注 mask 留空 |
| 关联 | 只登记有依据的候选/已验证关系及失败原因；零已验证配对也是合法结果 |
| 试标 | mask 同源尺寸、合法类别、证据与双标/复核记录；不能生成模拟 gold |
| 读取 | 无 split 的片段检查模式读取全部目标图像；有标签子集检查 image/mask 同步变换 |
| 重跑 | 同来源/配置不改变 ID，不增加重复观测、不覆盖人工字段或 mask |
| 结束 | checks.txt 列出通过、失败、阻塞和未执行；报告不把未执行检查写成通过 |

无 split 读取模式已实现：允许 `split=None` 并显式提供 `sequences`，只读检查/推理时 `require_mask=False`。正式训练仍要求固定 split 与 verified group，不为兼容原型伪造划分。
