# 协议变更记录

## Python包0.4.3 — 2026-10-26

数据集界面新增visible/infrared切换，支持直接打开infrared镜头images及仅含红外的索引。8位红外显示图像支持原尺寸浏览、缩放平移、逐帧切换和像素读数（注明非温度）；红外模式禁用现有可见光分割/估参及草稿输出，隐藏地平线控制点，避免误套用亮度假设。切回可见光恢复独立参数，不改动源图与标签。

## Python包0.4.2 — 2026-10-26

原图/结果画布支持鼠标像素读数：缩放平移后的原尺寸坐标、原图RGB、与阈值一致的通道亮度均值，以及当前显示掩码的ID/类别。标记参数变化后的上次结果；留白、移出、换图清除读数。未改变分割算法或标注输出。

## Python包0.4.1 — 2026-10-26

增加sea_mode=mixed/ice_only/water_only，处理可见海面缺少某一类时亮度二分造成的暗角误标。单类模式由人工明确指定，按原尺寸地平线/忽略带填充海面，跳过GrabCut和自动亮度估计；不是自动判断无水。模式随配置和逐图来源保存，批量提示适用整个任务；旧未声明参数按mixed兼容且保留旧哈希。类别/审核流程不变。

## Python包0.4.0 — 2026-10-26

增加DatasetWorkspace索引管理与GUI数据集入口：直接打开north16根目录，选择片段/可见光镜头；protocol.yaml统一指定drafts、profiles、projects输出目录。草稿保留原帧名与全局ID、批次samples及输入回执，取消保留成功子集；原图、正式索引/标签不被草稿覆盖。切换镜头独立记忆参数，X-AnyLabeling导出自动定位并保留样本身份。启动器默认打开数据集根目录，CLI增加--dataset。未扩展infrared算法或正式审核晋升。

## Python包0.3.2 — 2026-10-26

修正自动地平线的过度接受：默认保留当前地平线，仅估计冰水阈值，明确默认线也需人工定位。主动尝试地平线时，增加颜色/纹理线索一致性和竞争边缘拒绝；低可靠性候选不再替换当前线，取消“证据较强”提示。保留当前线的记录不再误称为已人工定位。实际back_04旧误检样例已验证被拒绝；该修订不代表达到地平线定位精度指标。

## Python包0.3.1 — 2026-10-26

新增当前图片自动参数估计与后台预览：颜色/纹理过渡候选地平线、海域Otsu亮度分组及分位数种子，证据不足保留原参数。允许保留手调地平线。估计依据按图像SHA256和参数哈希记录，随匹配配置与草稿保存；手动改参不错误继承旧依据。此功能提供启发式起点，仍需人工预览与多图验证，不改变类别或审核状态。

## Python包0.3.0 — 2026-10-26

新增可选PySide6调参界面与north16 gui入口；可视化地平线、参数校验、后台预览、多图抽样、配置记录、普通文件夹批处理、取消与编辑工程导出。新界面调用同一GrabCut核心，不再要求新参数复现旧参考图；旧CLI固定参数复现功能保留。类别与正式索引规则不变。详见GUI.md。

## Python包0.2.0 — 2026-10-24

补齐north16统一CLI、可选标注/训练依赖、__main__入口、随wheel携带的规范资源与init批次初始化。各业务模块保持职责与原接口；旧构建入口保留。支持wheel和源码分发，不把图像、标注工程或模型权重打入包。包版本变化不改变类别、标注状态、时间或split规则，详见PACKAGE.md。
