# 可见光—红外配准工作台

north16 0.5.0。目标是在没有专用标定板时打通“自动候选→人工修正→船只区域辅助→独立检查→保存工程与配准图”。这是图像配准工具，不把单应矩阵称为完整相机内外参标定。当前不输出焦距、畸变、米制基线、深度或已认证同步。

## 启动与输入

双击 `protocol/launch_registration.cmd`，本机默认读取 `E:/20261014`，输出父目录为 `E:/Dataset/north16/calibration`。

```powershell
north16 register --root E:\20261014 --output E:\Dataset\north16\calibration
```

支持原始抽帧布局 `camera/front_visible/lens_01/<时间>.jpg`、`front_infrared`、`back_visible`、`back_infrared`，也支持north16 `sequences/<片段>/<visible或infrared>/<镜头>/images`。按文件名交集列出候选帧，不按列表序号强行配对。16对候选通道分别管理，默认打开back_05；同编号不等于已经证明相机对应，需先看画面确认。不同模态保留原生分辨率，不以预览缩略图坐标存储标注。

E:/20261014现有数据为已导出的JPG，不是传感器RAW；已有日志使用帧号与时间日志行映射，不能仅凭同名认证硬同步。front_visible/lens_08的298张图经检查均为纯黑，自动配准明确拒绝纯色输入。

## 自动与人工流程

1. 打开根目录，选择相机对与时间。上方左图是可见光参考，右图是红外，底部是配准预览。
2. 点击“自动配准：全图匹配”。预览宽度最多1280进行CLAHE和SIFT提取，分别尝试原灰度、红外反相、梯度幅值匹配，Lowe比率0.78，使用RANSAC，求解仍在两图原生坐标中。自动候选以几何内点数、比例、分布、变换尺度和共同视场检查筛选；默认单应至少12内点，仿射至少8内点。不保证任何跨模态图片都能自动成功，失败时不强行生成变换。阈值为首版工程启发式，不代表已建立benchmark精度门槛。
3. 自动点显示黄色，排除点默认不绘制，但保留在表格；可勾选显示。切换“点选对应位置”，依次点击两图同一物理点完成一对。滚轮缩放，“拖动／缩放”模式平移。坐标表允许直接修改，删除选中点后可重新点击。
4. role为fit时参与拟合，check仅作独立检查，reject排除。手动单应至少4对非共线拟合点，仿射首版至少3对。对独立检查点不得从自动匹配点随意改名冒充独立真值，应由人工另外确认同一物理位置。
5. 点击“根据拟合点重新计算”。界面显示拟合内点残差及当前求解帧的检查点误差，单位为可见光原尺寸像素。拟合残差不是独立精度。检查点/拟合点修改后旧变换标记过期，过期变换不随保存导出图片。
6. 查看透明叠加、棋盘格、配准红外及有效区域。切换其他时间仍可预览当前固定变换，求解时间与当前时间同时显示；不同帧新选的检查点需要在该帧重新计算后才进入当前误差统计，本版没有自动跨帧误差汇总。相机分辨率变化会使旧变换失效。

全局单应只适合某参考平面或近似距离范围。近船、远岸和本船结构可能无法同时精确对齐，参数在码头的拟合误差不能证明海上不同距离海冰的精度；不同日期或装置重新安装后需要重新验证。首版未校正镜头畸变，边缘残差不应靠增加错误对应点消除。

## 船只区域与已有标注

“船只区域”页支持：

- 选择两种模态各自的本地Ultralytics .pt权重；自动检测仅保留名称中含boat/ship/cargo/vessel/tug的类别，不自动下载模型。本机默认通用yolo11s.pt，COCO boat类别；它没有针对热红外的可靠性保证。检测器为可选依赖 `north16[detection]`，CPU推理，模型哈希和阈值随工程保存。
- “画船只候选框”工具在两图分别拖框，删除误检并补充漏检。检测会替换旧检测候选，但保留手工框及导入标注；船只关联在检测后清空，避免索引误配。
- 导入当前图像的X-AnyLabeling矩形/多边形或COCO bbox；检查文件名与尺寸。仅导入明确船舶类，语义分割中的other不是船只类别，不能直接用于识别船舶。COCO若包含同名跨相机图片，需先导出本镜头独立清单。
- 用V/I编号人工确认同一条船，建立一一关联。点击“根据已关联船框自动配准”，只在每对船只区域内找对应特征，再计算几何变换。

船框中心及四角不是同一物理位置，不直接用于求单应性。不按检测顺序自动关联不同船只。如果框内匹配不足或点分布退化，程序拒绝；此时在船桥角点、桅杆连接点等位置手动点选，或结合固定码头结构。单艘远船面积很小，不能据此声称整幅图像得到可靠约束。

## 输出与恢复

```text
calibration/
  capture/back_05/<批次>/
    project.json                   对应点、船框/关联、来源哈希、变换、参数和状态
    infrared_registered.png        当前红外映射到可见光原生坐标系
    valid.png                      255有来源，0无来源
    overlay.jpg                    仅有效区域叠加
    checksums.json
```

数据根为north16时，capture替换为sequence。每次保存创建独立批次，不覆盖旧工程。允许没有变换时只保存点/框工程，或旧变换过期时只保存工程；配准图片只在当前变换有效时导出。加载project.json时验证全部已标注帧的来源哈希，可恢复这一个相机对的多帧标注和最后一个有效变换。原图只读，16位图像拒绝隐式转换。

所有结果均为candidate_unreviewed；不复制正式分割标签，不写入datasets的正式masks、samples、sync配准认证。有效掩码只是图像来源覆盖，不代表几何误差可接受，也不能消除遮挡差异。

首版保存当前帧结果，不提供视频重解码、硬同步求解、完整双目标定、深度配准或整段自动传播真值。确认固定变换质量后再扩展批量导出与同步/配准协议登记。

## 模块

registration/dataset.py读取布局；geometry.py负责拟合与几何检查；matching.py负责自动候选；detector.py负责可选本地检测；ship_annotations.py读取外部船只标注；storage.py管理工程与原图保护；canvas.py、window.py、app.py管理Qt交互与后台任务。标注GUI独立保留，不加载配准工程。
